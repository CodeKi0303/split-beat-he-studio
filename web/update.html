C86 / LOCAL USB UPDATE

좌우 펌웨어를 확인하고 업데이트

왼쪽 PC용 USB를 사용합니다. 오른쪽은 좌우 연결 케이블을 유지한 상태로 왼쪽을 통해 기록합니다.

최초 한 번은 양쪽에 새 부팅부를 SWD로 설치해야 합니다.
현재 0.1 / 0.2 펌웨어만으로는 USB 업데이트를 시작할 수 없습니다. 이 화면을 열거나 파일을 고르는 동작만으로 기록하지 않습니다.

Studio에서 필요한 설정을 먼저 키보드에 저장하고 연결을 종료하세요. 업데이트는 저장된 설정 영역을 보존하지만 저장하지 않은 RAM 설정은 재시작 때 사라집니다. 이 화면은 설정을 자동 저장하거나 키 출력을 켜지 않습니다.

1. 대상과 패키지

정식 릴리스 확인 중

선택한 파일 없음

크기, CRC32, SHA256, 앱 내부 좌우 식별자를 검사합니다. 해시 검사는 파일 손상 검사이며 게시자 서명 인증은 아닙니다.

2. 장치 확인

양쪽 버전을 읽는 동안 왼쪽이 중계 모드로 전환됩니다.

연결되지 않음

오른쪽부터 기록합니다. 이미 같은 이미지가 실행 중인 쪽은 건너뜁니다. 도중에 끊겼다면 양쪽 전원을 완전히 분리했다가 연결한 뒤 같은 파일로 다시 확인하세요.
